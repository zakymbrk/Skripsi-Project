LISTING 5.2 VALIDASI RADIUS LOKASI
======================================================================

Sumber: application/libraries/Rule_based_validation.php
Method: validate_geolocation()

$lat_dudi = $dudi_info->latitude;
$lon_dudi = $dudi_info->longitude;
$radius = !empty($dudi_info->radius)
    ? (float) $dudi_info->radius
    : 100.0;

if (empty($lat_siswa) || empty($lon_siswa)) {
    return [
        'is_valid' => false,
        'rule_id' => 'RBV-006',
        'status_lokasi' => 'tidak_valid',
        'message' => 'Koordinat GPS tidak terdeteksi.'
    ];
}

$jarak = $this->calculate_distance(
    $lat_siswa,
    $lon_siswa,
    $lat_dudi,
    $lon_dudi
);

if ($jarak > $radius) {
    return [
        'is_valid' => false,
        'rule_id' => 'RBV-006',
        'jarak' => $jarak,
        'radius' => $radius,
        'status_lokasi' => 'tidak_valid',
        'message' => 'Lokasi berada di luar radius DUDI.'
    ];
}

return [
    'is_valid' => true,
    'rule_id' => 'RBV-PASS',
    'jarak' => $jarak,
    'radius' => $radius,
    'status_lokasi' => 'valid'
];

Penjelasan:
Koordinat siswa dibandingkan dengan koordinat DUDI menggunakan perhitungan
Haversine. Presensi dinyatakan valid apabila jarak siswa tidak melebihi radius
yang telah ditentukan pada data DUDI.

LISTING 5.4 MONITORING PRESENSI
======================================================================

Sumber: application/models/M_presensi.php
Method: get_presensi_by_pembimbing()

public function get_presensi_by_pembimbing(
    $pembimbing_id,
    $tanggal = null,
    $siswa_id = null
) {
    $this->db->select(
        'p.*, s.siswa_nama, s.siswa_kelas,
         d.dudi_nama'
    );

    $this->db->from('tb_presensi p');
    $this->db->join(
        'tb_siswa s',
        's.siswa_id = p.siswa_id'
    );
    $this->db->join(
        'tb_pengelompokan k',
        'k.siswa_id = s.siswa_id'
    );
    $this->db->join(
        'tb_dudi d',
        'd.dudi_id = s.dudi_id',
        'left'
    );

    $this->db->where(
        'k.pembimbing_id',
        $pembimbing_id
    );

    if (!empty($tanggal)) {
        $this->db->where('p.tanggal', $tanggal);
    }

    if (!empty($siswa_id)) {
        $this->db->where('p.siswa_id', $siswa_id);
    }

    return $this->db
        ->order_by('p.tanggal', 'DESC')
        ->get()
        ->result();
}

Penjelasan:
Program mengambil data presensi berdasarkan guru pembimbing. Data yang diambil
meliputi identitas siswa, tanggal, jam masuk, jam pulang, status kehadiran,
dan informasi DUDI.

LISTING 5.7 SINKRONISASI NILAI MONITORING
======================================================================

Sumber: application/libraries/Rule_based_validation.php
Method: sync_penilaian_siswa()

$pengurangan_logbook =
    $total_tidak_valid * 5.0;

$pengurangan_kehadiran =
    ($total_alpha + $total_terlambat) * 5.0;

$nilai_kehadiran =
    max(0, 100 - $pengurangan_kehadiran);

$nilai_akhir = round(
    ($nilai_kehadiran * 0.40) +
    ($nilai_logbook * 0.60),
    2
);

$data_penilaian = [
    'siswa_id' => $siswa_id,
    'total_kehadiran' => $total_hadir,
    'total_bolos' => $total_alpha,
    'total_terlambat' => $total_terlambat,
    'total_logbook_valid' => $total_valid,
    'total_logbook_tidak_valid' => $total_tidak_valid,
    'total_pengurangan_nilai' => $pengurangan_nilai,
    'nilai_kehadiran' => $nilai_kehadiran,
    'nilai_logbook' => $nilai_logbook,
    'nilai_akhir' => $nilai_akhir
];

Penjelasan:
Sistem menghitung nilai berdasarkan data kehadiran dan logbook. Nilai akhir
terdiri dari bobot nilai kehadiran sebesar 40 persen dan nilai logbook sebesar
60 persen. Hasil perhitungan disimpan pada tabel tb_penilaian.
