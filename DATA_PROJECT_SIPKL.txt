7. FITUR SISWA
--------------
- Mengisi dan mengirim pengajuan PKL.
- Memilih kelas, periode, DUDI, telepon, dan alamat.
- Memantau status pengajuan.
- Mengunggah surat permohonan/pernyataan dalam format JPG, PNG, GIF, PDF,
  DOC, DOCX, XLS, XLSX, PPT, atau PPTX maksimal 5 MB.
- Presensi masuk dan pulang memakai GPS, foto, dan geolocation.
- Mengisi satu logbook setiap hari setelah melakukan presensi masuk, dengan
  dokumentasi JPG, PNG, GIF, PDF, DOC, DOCX, XLS, XLSX, PPT, atau PPTX.
- Melihat catatan pembimbing pada logbook.
- Mencetak ID Card dengan QR Code setelah disetujui.
- Mengelola profil dan password.
- Melihat nilai dan rincian rekap hanya setelah status PKL selesai.

8. FITUR PERUSAHAAN TIDAK TERDAFTAR
------------------------------------
Jika siswa memilih "Lainnya (Perusahaan tidak terdaftar)":
- Mengisi nama dan data lengkap perusahaan.
- Menekan tombol "Ambil Lokasi" pada form pengajuan.
- Browser mengambil latitude dan longitude perusahaan.
- Latitude wajib berada pada -90 sampai 90.
- Longitude wajib berada pada -180 sampai 180.
- Koordinat disimpan pada tb_siswa.other_dudi_latitude dan
  tb_siswa.other_dudi_longitude.
- Hubin dapat melihat koordinat saat melakukan review.
- Saat disetujui, koordinat dipindahkan ke tb_dudi.latitude dan
  tb_dudi.longitude.
- Koordinat tersebut dapat digunakan untuk validasi presensi berikutnya.

11. PERHITUNGAN NILAI TERBARU
-----------------------------
Nilai Kehadiran = max(0, 100 - ((total bolos + total terlambat) x 5))

Nilai Logbook:
- Jika ada logbook valid yang sudah dinilai pembimbing,
  nilai logbook = rata-rata nilai_pembimbing.
- Jika belum ada nilai pembimbing,
  nilai logbook = max(0, 100 - (logbook tidak valid x 5)).

Nilai Akhir = (Nilai Kehadiran x 0.40) + (Nilai Logbook x 0.60)

Catatan konsekuensi:
- Bolos/alpha mengurangi nilai 5% atau 5 poin per kejadian.
- Terlambat dihitung jika presensi masuk setelah pukul 08:00 dan mengurangi
  nilai 5% atau 5 poin per kejadian.
- Rincian jumlah bolos, terlambat, dan total pengurangan dapat dikontrol oleh
  Pembimbing dan Hubin melalui laporan.

Nilai pembimbing disimpan per logbook pada tb_logbook.nilai_pembimbing.
Nilai rekap disinkronkan oleh Rule_based_validation::sync_penilaian_siswa().

12. RULE-BASED VALIDATION
-------------------------
RBV-001  Presensi masuk belum ada pada tanggal tersebut dan siswa disetujui
RBV-002  Presensi pulang setelah atau sama dengan jam masuk
RBV-003  Parameter presensi lengkap
RBV-004  Foto presensi wajib untuk status hadir
RBV-005  Format foto dan ukuran maksimal 2048 KB
RBV-006  Jarak GPS dalam radius DUDI
RBV-007  Maksimal satu logbook per siswa per tanggal
RBV-008  Deskripsi logbook minimal 20 karakter
RBV-009  Foto logbook wajib
RBV-010  Parameter logbook lengkap
RBV-011  Tanggal logbook tidak boleh masa depan
RBV-012  Jam masuk antara 05:00 sampai 23:59
RBV-013  Jam pulang setelah jam masuk
RBV-014  Siswa harus tercatat hadir saat logbook dibuat
RBV-015  Hak akses monitoring sesuai level dan status pengajuan
RBV-016  Sinkronisasi nilai dan penalti otomatis

Jika database lama belum memiliki kolom perusahaan lain:
ALTER TABLE tb_siswa
  ADD COLUMN other_dudi_latitude DECIMAL(10,8) DEFAULT NULL,
  ADD COLUMN other_dudi_longitude DECIMAL(11,8) DEFAULT NULL;

Jika database lama belum memiliki nilai pembimbing:
ALTER TABLE tb_logbook
  ADD COLUMN nilai_pembimbing DECIMAL(5,2) DEFAULT NULL
  AFTER catatan_pembimbing;

16. RIWAYAT PERUBAHAN TERBARU
-----------------------------
- Penambahan latitude dan longitude pada pengajuan siswa untuk DUDI yang
  belum terdaftar atau belum bekerja sama dengan sekolah.
- Penambahan pengambilan lokasi melalui Browser Geolocation API.
- Penambahan validasi rentang latitude dan longitude di server.
- Penyalinan koordinat perusahaan baru ke data tb_dudi saat disetujui Hubin.
- Perbaikan kompatibilitas database lama melalui Database_sync.
- Pembatasan tampilan nilai siswa sampai status pengajuan menjadi selesai.
- Rincian nilai siswa tidak ditampilkan sebelum PKL selesai.
- Penambahan input nilai pembimbing 0-100 pada review logbook.
- Penambahan kolom tb_logbook.nilai_pembimbing.
- Nilai logbook menggunakan rata-rata nilai dari pembimbing.
- Nilai akhir menggunakan bobot kehadiran 40% dan logbook 60%.
- Pembimbing dapat melihat dan mencetak laporan bimbingan.
- Hubin dapat mengontrol dan mencetak rekapitulasi monitoring.

17. CATATAN KEAMANAN
--------------------
- Hak akses pembimbing dibatasi pada siswa bimbingannya.
- Siswa hanya dapat melihat data miliknya sendiri.
- Password disimpan menggunakan bcrypt.
- Validasi data dilakukan server-side.
- Validasi geolocation presensi dilakukan server-side menggunakan formula
  Haversine.
- File upload dibatasi berdasarkan tipe dan ukuran.
